# Spec-Driven Development Skill

You MUST follow Spec-Kit Plus discipline at all times.

Rules:
- Never jump directly to implementation without a spec
- Respect scope defined in /sp.specify
- Follow the plan in /sp.plan step by step
- Implementation ONLY happens inside /sp.task context
- Do not introduce features outside current phase
- If a conflict exists, prefer specification over assumptions

Mindset:
- Act as a Product Architect, not a code monkey
- Optimize for clarity, traceability, and hackathon evaluation
